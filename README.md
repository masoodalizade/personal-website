# سایت شخصی مسعود علیزاده

وب‌سایت مینیمال فارسی، شامل تایملاین تجربه‌ها و صفحه یادداشت‌ها. کد بدون وابستگی و آماده انتشار روی GitHub Pages است.

## صفحات
- `index.html` — تجربه‌ها، خط زمانی مرکزی، رویدادهای دوطرفه و سال‌های غیرتکراری
- `notes.html` — فهرست یادداشت‌ها
- `post.html?id=...` — متن هر یادداشت
- `experience.html?id=...` — روایت هر تجربه، تصویرها، ویدیوها و شاهدها
- `admin/` — پنل ویرایش تجربه‌ها و یادداشت‌ها، با ذخیره مستقیم در GitHub

## مدیریت محتوا
در `data/events.json` تجربه‌ها و در `data/notes.json` یادداشت‌ها را ویرایش کنید. یادداشت‌های پیش‌نویس با `published:false` پنهان می‌مانند. برای نمایش یک یادداشت، `published:true` بگذارید و متن کامل را در `body` قرار دهید. بعد از commit سایت با GitHub Actions بازنشر می‌شود.

هر تجربه یک `id` ثابت دارد؛ تغییر عنوان، سال یا ترتیب، لینک آن را عوض نمی‌کند. `body` متن روایت است؛ بندها با خط خالی جدا می‌شوند و `**متن**` به صورت برجسته نمایش داده می‌شود. `image` و `imageAlt` تصویر اصلی و توصیف آن هستند. `media` فهرست مرتب `{type: "image" | "video", url, caption, alt?}` و `evidence` فهرست `{title, url}` است. فیلدهای خالی در صفحه عمومی نمایش داده نمی‌شوند و تجربه‌های `published:false` هم در تایملاین و هم در صفحه جزئیات پنهان‌اند.

از پنل می‌توان فایل تصویر یا ویدیو تا ۲۵ مگابایت انتخاب کرد یا لینک فایل را وارد کرد. ویدیوهای مستقیم با پخش‌کننده مرورگر، YouTube و Vimeo با پخش‌کننده تعبیه‌شده و سرویس‌های دیگر با لینک تماشا نمایش داده می‌شوند. فایل‌ها همراه متن در یک commit ذخیره می‌شوند. توکن در حافظه همان صفحه می‌ماند و فقط به `Contents: Read and write` روی همین مخزن نیاز دارد. تغییرات ذخیره‌نشده هر بخش هنگام جابه‌جایی بین تجربه‌ها و یادداشت‌ها حفظ می‌شوند؛ هر بخش جداگانه ذخیره می‌شود.

بررسی منطق نمایش و ذخیره: `node --test tests/*.test.cjs`.
