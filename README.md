# سایت شخصی مسعود علیزاده

وب‌سایت مینیمال فارسی، شامل تایملاین تجربه‌ها و صفحه یادداشت‌ها. کد بدون وابستگی و آماده انتشار روی GitHub Pages است.

## صفحات
- `index.html` — تجربه‌ها، خط زمانی مرکزی، رویدادهای دوطرفه و سال‌های غیرتکراری
- `notes.html` — فهرست یادداشت‌ها
- `post.html?id=...` — متن هر یادداشت
- `admin/` — مسیرهای ساده ویرایش محتوای GitHub (این یک CMS با فرم اختصاصی نیست)

## مدیریت محتوا
در `data/events.json` تجربه‌ها و در `data/notes.json` یادداشت‌ها را ویرایش کنید. یادداشت‌های پیش‌نویس با `published:false` پنهان می‌مانند. برای نمایش یک یادداشت، `published:true` بگذارید و متن کامل را در `body` قرار دهید. بعد از commit سایت با GitHub Actions بازنشر می‌شود.

## عکس اصلی
فعلاً فایل `assets/portrait.jpg` هنوز بارگذاری نشده و تصویر نمایه GitHub به‌عنوان جایگزین استفاده می‌شود. عکس واقعی دلخواه را با همین نام در مخزن آپلود کنید.

## انتشار
در Settings → Pages، منبع را GitHub Actions انتخاب کنید. سپس در Actions، workflow «Deploy GitHub Pages» را اجرا کنید. نشانی مورد انتظار: https://masoodalizade.github.io/personal-website/ . تا زمان فعال‌شدن Pages، این نشانی الزاماً در دسترس نیست.

## نکته
رویدادها برای شروع انتخاب شده‌اند؛ تاریخ‌ها و توضیحات باید توسط صاحب سایت بازبینی شوند. هیچ نوشته کامل و تأییدنشده‌ای به‌عنوان مقاله منتشر نشده است.
