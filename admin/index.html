برای ویرایش رویدادها یا یادداشت‌ها، فایل مربوطه در GitHub باز می‌شود. پس از ذخیره تغییرات، سایت دوباره منتشر خواهد شد. این نسخه پنل ویرایش مستقیم نیست و ورود از طریق GitHub انجام می‌شود.

برای افزودن یک رویداد، یک شیء جدید در آرایه JSON وارد کن. برای انتشار یادداشت، مقدار published را true قرار بده. متن‌ها نباید شامل اطلاعات خصوصی باشند.
