مدیریت سایت

تجربه‌ها و یادداشت‌ها را از همین صفحه ویرایش کن. ذخیره‌سازی مستقیماً در مخزن GitHub انجام می‌شود و انتشار سایت چند دقیقه طول می‌کشد.

اتصال امن به مخزن

برای ذخیره تغییرات، یک توکن محدود GitHub با دسترسی Contents: Read and write فقط برای مخزن personal-website لازم است. توکن تنها تا زمانی که این صفحه باز است در حافظه نگه داشته می‌شود و روی سایت یا در مرورگر ذخیره نمی‌شود.
